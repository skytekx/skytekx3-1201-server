Create: Integrated Farming, modified unofficial SkyTekx build for Forge 1.20.1
==============================================================================

This is a MODIFIED, UNOFFICIAL version of Create: Integrated Farming. It is not made, supported or
endorsed by DragonsPlus. Please report problems with this build to SkyTekx
(https://github.com/skytekx/skytekx3-1201-server/issues), not to the upstream project.

Modifications
-------------
  Modified by SkyTekx in November 2026 for the SkyTekx 3 modpack: ported from NeoForge 1.21.1 to
  Minecraft 1.20.1 with Forge 47 and Create 6.0.8. The mod id create_integrated_farming stays, and
  the version is 1.4.3-skytekx.1.

  Summary of the changes:
  - Build: ForgeGradle 6 on Java 17 instead of ModDevGradle on Java 21, a reproducible jar, and this
    NOTICE, the license texts and Create's MIT notice inside the jar. The integrations are
    reobfuscated against the mods they call.
  - Port: the NeoForge 1.21.1 API is replaced by its Forge 47 counterparts. One @Mod entry point
    constructs the client, data and integration entry points. The roost, the vacuum harvester and
    the Farmer's Delight basket use Forge capabilities. The chicken food data maps are read by the
    mod itself on every data pack reload and sent to clients over the network channel
    create_integrated_farming:main (protocol 1), which also carries the roosting display data.
    Blocks use Block#use, loot tables come from the loot data manager, and the fishing nets use
    the 1.20.1 enchantment and loot parameter forms. The Create mixins target Create classes only.
  - Data: the data files use the 1.20.1 folder names and formats, forge: tags (forge:rods/wooden,
    forge:plantoil) and the new item tag create_integrated_farming:chicken_food with the chicken
    foods of 1.20.1. The chicken food maps take using_converts_to in the 1.21.1 object form and as
    a plain item id. The Lava Fishing Net drops itself in code, since 1.20.1 loot tables have no
    load conditions.
  - Fixes: the chicken roost drops a copy of the chicken food remainder, so every feeding returns
    it. The recipe advancements name the crafting recipe ids, so they unlock the recipes. The roost
    Ponder scene stores its egg as a 1.20.1 item stack.
  - Addition: Lava Fishing (mod id lavafishing) provides the catches of the Lava Fishing Net and
    enables it, in the way the upstream Nether Depths Upgrade integration does.
  - Removed: the integrations of 26 mods that the SkyTekx pack does not carry, with their duck,
    goose, turkey and warm or cold chicken roosts. Farmer's Delight, Supplementaries and Twilight
    Delight stay.

  The complete change history is the git history of the ports/createintegratedfarming directory of
  https://github.com/skytekx/skytekx3-1201-server
  That directory is the Corresponding Source of this jar: the exact source of a given jar is that
  directory at the commit that last changed the jar in local-mods/, and it builds the same jar again
  (see ports/createintegratedfarming/UPSTREAM.md). UPSTREAM.md lists every change.
